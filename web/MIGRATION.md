# המרה ל‑Next.js + React + TypeScript

האתר הועבר מ‑HTML/CSS/JS סטטי ל‑**Next.js 16 (App Router) + React 19 + TypeScript 5.9**. התוכן והעיצוב לא שונו — ההמרה אומתה מול המקור בהשוואת פיקסלים.

## איפה האתר החי

**האפליקציה החיה היא `web/`.** התיקייה `design/` נשארה כפי שהיא, כמקור ההשוואה המקורי. אין לערוך את `design/` ולצפות לשינוי באתר, ואין לתת לשתי הגרסאות להתפצל.

```
npm run dev     # שרת פיתוח
npm run build   # בנייה לייצור
npm start       # הרצת הבנייה
```

## מיפוי הקבצים

כל מסמך HTML הפך ל‑route group עם root layout משלו: `index.html` → `/`, `chapters.html` → `/chapters`, `chapter6.html` → `/chapter6`, `home.html` → `/home`.

הסיבה ש‑layout נפרד לכל עמוד ולא אחד משותף: משתני ה‑`:root` של העמודים באמת סותרים זה את זה — ב‑`index.html` הערך של `--maroon` הוא `#4a101e`, ובשאר האתר `#841b1b`. ב‑layout משותף הגיליון האחרון שנטען היה דורס את הראשון. root layout לכל קבוצה משחזר בדיוק את הבידוד שהיה בין ארבעה מסמכים נפרדים.

`chapter6-lesson.html` לא הועבר — הוא קובץ ישן שאינו מקושר לאף מקום (מתועד ב‑`CHAPTER6_FIX_REPORT.md`). הוא נשאר ב‑`design/`.

## פרק 6

המנוע והמנגנונים (כ‑3,700 שורות) הועברו ל‑TypeScript **מילה במילה**. React מרנדר רק את המעטפת; `#chapter` ו‑`#rail-list` נשארים ריקים ב‑JSX והמנוע ממשיך לבנות אותם באופן אימפרטיבי — זה מה שאיפשר להעביר קוד DOM מדוד ומוכח בלי לגעת בו.

ארבעת המשתנים הגלובליים נעלמו: `window.CH6` → `data.ts`, `window.CH6M` → `mechanisms.ts`, `window.CH6E` → `runtime.ts`, `window.CH6_START` → `engine().start()`.

- `data.ts` **מיוצר בסקריפט** מ‑`data.js` ומאומת deep‑equal מולו. אין להקליד אותו מחדש.
- `mechanisms.ts` קורא לרשמים בסדר שבו נטענו תגי ה‑`<script>`. **`registerChecks` אחרון** — הוא בעלים של מזהי התרגולים וחייב לדרוס את הקבצים שעדיין עונים להם.
- 23 המנגנונים המושבתים הועברו כמות שהם, לא נמחקו.
- `createEngine()` ו‑`initFilm()` מחזירים `destroy()`. תג `<script>` לא נדרש לנקות אחריו; אפקט של React כן — ב‑StrictMode הוא נטען פעמיים בכוונה.

## שני אילוצי סביבה שנכפו עלינו

**webpack ולא Turbopack.** Turbopack לא מצליח לבנות מהתיקייה הזו כלל: הוא חותך מחרוזת נתיב לפי אינדקס בייטים, והחיתוך נופל באמצע אות עברית בשם `אסלאם` וקורס — `start byte index 9 is not a char boundary; it is inside 'א'`. זה באג של Turbopack. לכן `--webpack` ב‑`dev` וב‑`build`.

**TypeScript מקובע ל‑5.9.3.** `npm i -D typescript` מתקין היום גרסה 7 (הפורט ל‑Go), שאין לה נקודת כניסה ל‑JS API. Next נכשל עליה עם `The "id" argument must be of type string`. גרסה 7 גם פוסלת `baseUrl`, ולכן ה‑alias של `@/` מוגדר ב‑`next.config.ts`.
